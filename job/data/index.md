## 핵심 요약

데이터 분석 자소서에서 가장 먼저 보는 것은 문제 정의와 데이터 검증 역량입니다. 경험은 문제 정의, 데이터와 방법, 분석·모델 결과, 지표 변화의 순서로 쓰고, 결과를 숫자로 끝내세요.

- 경험 문장은 문제 정의, 데이터와 방법, 분석·모델 결과, 지표 변화의 순서로 씁니다.
- 평가 지표를 고른 이유와 데이터의 한계를 한 문장씩 밝히면 분석가의 판단이 보입니다.
- 도구 이름보다 분석 결과로 바뀐 의사결정을 쓰는 것이 강합니다.
- 지원 직무에 데이터 분석을 넣으면 합불이 데이터 직무 사전으로 직무 표현과 수치 근거를 대조해 판정합니다.

## 데이터 분석 직무는 무슨 일을 하나요?

데이터 분석 직무는 데이터로 문제를 정의하고 분석과 모델로 의사결정을 돕는 일입니다. 파이썬, SQL, 머신러닝을 다룰 줄 아는 지원자는 많습니다. 데이터 직무 서류를 가르는 것은 문제를 어떻게 정의했는지와 숫자가 말하는 것과 말하지 않는 것을 구분했는지입니다. 데이터의 한계를 한 문장 밝히는 것만으로도 분석가의 태도가 보입니다.

## 데이터 분석 서류에서는 무엇을 먼저 보나요?

이 직무의 서류에서 가장 먼저 보는 것은 **문제 정의와 데이터 검증 역량**입니다. 경험을 쓸 때는 **문제 정의, 데이터와 방법, 분석·모델 결과, 지표 변화**의 순서를 지키면 심사자가 찾는 정보가 빠짐없이 들어갑니다. 순서가 바뀌거나 결과의 숫자가 빠지면 같은 경험도 근거 없는 주장으로 읽힙니다.

## 데이터 분석 자소서에 넣을 직무 용어는?

용어는 나열하지 말고 경험 문장 안에서 쓰세요. 합불은 문서에 이런 직무 표현이 얼마나 들어 있는지 직무 사전으로 대조하고, 합격예측에서는 내 문서에 빠진 용어와 넣는 방법을 알려 줍니다.

| 용어 | 뜻과 서류에 쓰는 법 |
| --- | --- |
| 전처리 | 분석 전에 빠진 값, 튀는 값, 형식을 정리하는 일입니다. 정리한 데이터 규모와 기준을 씁니다. |
| 피처 | 모델에 넣는 입력 변수입니다. 새로 만든 피처와 그 효과를 씁니다. |
| A/B 테스트 | 두 안을 나눠 보여 주고 지표 차이를 비교하는 실험입니다. 표본 수와 결과 차이를 씁니다. |
| 검정 | 차이가 우연인지 통계로 확인하는 일입니다. 쓴 방법과 결론을 씁니다. |
| 대시보드 | 핵심 지표를 한 화면에서 보게 만든 도구입니다. 누가 무엇을 결정하는 데 썼는지 씁니다. |
| 지표 | 목표를 재는 숫자입니다. 무엇을 지표로 정했고 왜 그 지표인지 씁니다. |

## 데이터 분석 입사 후 포부는 어떻게 쓰나요?

입사 후 포부는 맡을 일, 관리할 지표, 기간이 들어가야 다짐이 아니라 계획으로 읽힙니다. 아래 틀의 괄호를 본인이 지원한 회사와 직무에 맞게 채우세요.

입사 후 1년 안에 [담당 서비스]의 핵심 지표를 정의해 대시보드로 관리하고, [예측·추천] 모델로 [지표]를 개선하는 과제를 맡겠습니다.

일하는 원칙을 묻는 문항이라면 "숫자가 말하는 것과 말하지 않는 것을 구분하기"처럼 행동으로 확인할 수 있는 원칙 하나를 고르고, 그 원칙을 지킨 경험을 바로 붙이세요.

## 데이터 분석 면접에서는 무엇을 묻나요?

면접 질문은 대부분 서류에 쓴 경험에서 출발합니다. 서류를 내기 전에 아래 질문에 1분 안에 답할 수 있는지 확인하세요.

1. **모델 성능을 어떤 지표로 평가했고, 그 지표를 고른 이유는 무엇입니까?** 문제의 성격(데이터가 한쪽으로 치우쳤는지 등)과 고른 지표, 기준 모델과 견준 개선 수치를 함께 말하도록 준비하세요.
2. **A/B 테스트 결과가 통계적으로 유의하지 않게 나오면 어떻게 판단하겠습니까?** 표본 크기와 효과 크기를 먼저 점검하고, 추가 실험이나 다른 지표 확인 같은 다음 행동으로 답하세요.
3. **분석 결과로 실제 의사결정이 바뀐 경험이 있습니까?** 누가 무엇을 결정했는지, 분석이 무엇을 바꿨는지, 그 뒤 지표 변화를 순서대로 말하세요.

이 직무로 많이 지원하는 기업의 서류 기준은 [KT 자소서](https://hapbul.kr/kt/), [LG전자 자소서](https://hapbul.kr/lg/), [CJ 자소서](https://hapbul.kr/cj/)에서 볼 수 있고, 분량은 [자소서 글자수 세기](https://hapbul.kr/geuljasu/)로 먼저 맞출 수 있습니다.

## 자주 묻는 질문

### 데이터 분석 자소서에 공모전 경험만 있어도 되나요?

됩니다. 공모전이라도 문제를 어떻게 정의했는지, 데이터의 한계를 어떻게 다뤘는지, 결과가 어떤 결정으로 이어질 수 있는지를 쓰면 실무의 언어가 됩니다.

### 데이터 분석 자소서 합격 가능성을 미리 알 수 있나요?

합불(hapbul.kr)에 자기소개서를 올리고 지원 직무에 데이터 분석을 넣으면 데이터 직무 사전으로 직무 표현과 수치 근거를 대조해 판정합니다. 무료입니다.

### 정확도 같은 숫자를 많이 쓰면 유리한가요?

숫자의 양보다 그 숫자를 고른 이유가 중요합니다. 왜 그 지표로 평가했는지를 한 문장 붙이세요.

### 데이터 분석 자소서 지원동기는 어떻게 쓰나요?

분석 도구보다 지원 회사의 데이터로 풀고 싶은 의사결정 문제로 시작하세요. 근거 경험은 문제 정의, 데이터와 방법, 분석·모델 결과, 지표 변화 순서로 쓰고, 분석 결과가 실제 결정에 어떻게 쓰였는지까지 적습니다.
